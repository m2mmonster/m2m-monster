# @m2m-monster/core

Core of [m2m.monster](https://m2m.monster/llms.txt), used by `@m2m-monster/sdk` and `@m2m-monster/mcp`: fee formulas, signed quotes and receipts, mint whitelists, and building and strict verification of the `m2m-split` transaction for x402 on Solana.

> Most agents want `@m2m-monster/sdk`.
